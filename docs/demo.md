# IDE demonstration

The README animation contains six screens captured from a real Kakoune client:
the source Space menu, a definition jump, documentation with a signature, the
project explorer, a passing test at the cursor, and debugger variables with
their direct Space commands. It uses a small V project and the single-client
interface. Pane workflows are covered separately by automated real-client tests.

The demonstration is generated by `tests/record_demo.py`. It drives Kakoune in
a private tmux session, uses the installed VLS and GDB, and renders terminal
captures into a GIF. It uses separate settings, cache and a temporary project;
existing editor sessions and personal settings are preserved.

Contributors can regenerate it with a managed installation, a compatible V
compiler, Python 3.12+, Pillow, DejaVu Sans Mono, tmux and GDB with DAP:

```sh
python3 tests/record_demo.py /absolute/managed-prefix docs/assets/ide.gif
```

Add
`--frames /absolute/artifact-directory` to inspect individual PNG frames before
committing the animation. Failed recordings keep their temporary artifacts at
the path printed by the driver; successful recordings clean those files up.

This recorder is an optional presentation tool. It is not an installed IDE
helper and does not add a Python dependency to the editor experience. Users
are not required to record a demonstration or perform manual acceptance tests.
